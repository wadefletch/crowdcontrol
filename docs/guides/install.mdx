# How to Install crowdcontrol

This guide shows you how to install crowdcontrol on your system. Choose the method that works best for your environment.

## System Requirements

- **Operating System**: Linux, macOS, or Windows
- **Docker**: Version 20.10 or later
- **Git**: Version 2.25 or later
- **Node.js**: Version 16 or later (if using npm installation)

## Installation Methods

### Using Cargo (Recommended)

If you have Rust installed:

```bash
cargo install crowdcontrol-cli
```

### Using npm

```bash
npm install -g crowdcontrol-cli
```

### Binary Download

Download the latest binary from our [GitHub releases](https://github.com/your-org/crowdcontrol/releases):

<Tabs>
  <Tab title="Linux">
    ```bash curl -L
    https://github.com/your-org/crowdcontrol/releases/latest/download/crowdcontrol-linux
    -o crowdcontrol chmod +x crowdcontrol sudo mv crowdcontrol /usr/local/bin/
    ```
  </Tab>
  <Tab title="macOS">
    ```bash curl -L
    https://github.com/your-org/crowdcontrol/releases/latest/download/crowdcontrol-macos
    -o crowdcontrol chmod +x crowdcontrol sudo mv crowdcontrol /usr/local/bin/
    ```
  </Tab>
  <Tab title="Windows">
    Download the Windows executable and add it to your PATH.
  </Tab>
</Tabs>

## Verification

After installation, verify crowdcontrol is working:

```bash
crowdcontrol --version
crowdcontrol doctor
```

The `doctor` command will check your system for compatibility and report any issues.

## Configuration

crowdcontrol uses configuration files and environment variables. See the [Configuration Reference](/reference/configuration) for setup details.

This creates a configuration file at `~/.config/crowdcontrol/config.toml`.

## Docker Setup

Ensure Docker is properly configured:

1. Install Docker Desktop or Docker Engine
2. Start the Docker service
3. Verify Docker is running: `docker --version`

## Troubleshooting

<AccordionGroup>
  <Accordion title="Command not found">
    Make sure the installation directory is in your PATH environment variable.
  </Accordion>
  <Accordion title="Permission denied">
    On Unix systems, ensure the binary has execute permissions and is in a
    directory with appropriate access.
  </Accordion>
  <Accordion title="Docker connection issues">
    Verify Docker is running and your user has permission to access Docker.
  </Accordion>
</AccordionGroup>
